# Support

For usage questions and reproducible bugs, open a GitHub issue in the project repository.

Before reporting a problem, include:

- `scompress --version`
- Linux distribution and version
- `uname -m`
- `echo "$XDG_SESSION_TYPE"`
- `pkg-config --modversion gtk4` (for GUI issues)
- The exact command or GUI steps and the complete error output

Please do not attach private photographs or files that contain personal metadata. A generated test image is preferred.
